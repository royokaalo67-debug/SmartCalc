# SmartCalc

A responsive React + Vite MVP containing five browser-based calculators:
- Profit
- Markup
- Discount
- Break-even
- VAT

## Requirements
- Node.js 18 or newer
- npm (included with Node.js)

## Run locally
```powershell
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```powershell
npm run build
npm run preview
```

## Before public launch
- Replace the placeholder contact address and add real Privacy Policy, Terms, and About pages.
- Verify all calculations and tax assumptions for your intended markets.
- Add a custom domain and configure Search Console.
- Apply for Google AdSense only after the site has useful, original content and is ready for review.

This MVP does not fetch live exchange rates. Currency selection changes display formatting only; it does not convert values between currencies.
